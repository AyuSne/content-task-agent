# 需求分析（交付文档 01）

## 目标

为虚构视频剪辑 App「帧剪」的短视频推广活动建立一个可运行的内容任务 Agent：接收主题/预算/截止等输入，形成有依据、可核验、可保存、可续跑的活动方案；过程与结果落 SQLite，交付 Markdown/JSON/Trace，不伪造完成。

## 用户与场景

- 运营同学：给出任务输入，查看简报/方案/核验意见，必要时更新输入或导入人工稿。
- 评审/负责人：查看证据、核验结论、预算与用量，决定是否保存交付。
- 开发/维护者：通过 CLI 与确定性测试复现流程，通过真实模式观察模型行为。

## 功能需求（十四票）

1. 任务入口、校验、身份与模式隔离。
2. 业务简报、项目知识、检索与计量。
3. 独立脚本生成、完整活动方案、素材状态与证据。
4. 独立内容核验、核实保存、交付导出与执行报告。
5. 跨进程续跑、暂停、中断与结果未知恢复。
6. 核验意见处置、返修、复审与评估中断。
7. 资源/工具反馈后的策略比较、可行替代与停止缺口。
8. 保存未知核实、导出修复与不盲目重放。
9. 输入版本、资源/语义更新、知识与资料变更后的有效性复核。
10. 人工 Markdown 稿导入、基稿冲突、待核验与重导出。
11. 六对正反样例的评审校准与真实测量。
12. 真实 DeepSeek 核心运行、用量与失败证据。
13. 与单次生成基线的描述性对比。
14. 交付文档、证据索引、真实用量、评审与复盘。

## 非功能需求

- 权威状态：SQLite；CLI 是公开 seam；跨进程可观察。
- 可追溯：每轮消息、工具结果、尝试、账本、评审、保存、请求用量。
- 安全边界：资料正文是数据不是指令；未授权不得升级；不承诺涨粉/收益；不伪造成功。
- 预算/截止：模拟费用硬约束；真实 token 用量另记，真实金额未知。
- 可复现：Mock/脚本化模型边界；真实/Mock 数据目录、请求身份与报告分开。
- 隐私：`.env` 不入库；证据不含 Key；只记录 `api_key: set`。

## 边界

- 不接发布平台、不做真实投放、不抓取外部网页、不做文件监视/自动合并。
- 不证明生产质量或统计显著；真实模型单样本结果只作观察。
- 12 轮上限是每任务累计硬约束，不因续跑重置。

## 验收口径

以 `spec.md` 与十四票验收点为准；每票 red→green、CLI 证据、双轴评审与真实/确定性证据见 `docs/delivery/06-evidence-index.md`。无法满足的项在对应 README 明确写“未执行/未通过”，不以 Mock 冒充真实。
