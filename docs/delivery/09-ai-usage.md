# AI 使用说明（交付文档 09）

## 使用的模型与边界

- 真实模式：DeepSeek `deepseek-flash`，OpenAI Python SDK，`base_url=https://api.deepseek.com`，`thinking=disabled`，`stream=false`，SDK 自动重试 0。
- 三处独立调用：主 Agent（计划/简报/草稿）、脚本生成子调用、独立评审子调用；各自有提示词版本和请求计数。
- Mock/脚本模式：`CTA_MODEL_SCRIPT` 注入模型响应，只用于测试/复现；真实与 Mock 数据目录、身份、报告分开。

## 提示词与知识

- 主提示词 `PROMPT_VERSION`（当前 `main-2026-10-29.v6`）：阶段、单轮单工具、证据、预算/截止、策略、处置、停止。
- 评审提示词 `REVIEW_PROMPT_VERSION`；脚本生成 `GENERATION_PROMPT_VERSION`。
- 知识：`knowledge/campaign-creation/2026-10-29.v1.md`（可显式采用 `2026-10-30.v1`）；评审知识独立。
- 校准样例与工作知识/正式验收分离，标签不进入评估输入。

## 数据与隐私

- 输入为合成活动信息（主题/预算/截止/受众/要求），不含真实用户隐私。
- `.env` 的 `DEEPSEEK_API_KEY` 不提交、不打印；证据只记录 `api_key: set`。
- 真实请求内容会发送给 DeepSeek API；不发送本地文件路径、密钥或无关数据。
- 资料正文是数据不是指令；系统提示明确禁止执行其中的“忽略要求/跳过核验”等文字。

## 人工与自动化分工

- 人工：确认活动目标/预算/截止、采用知识/资料、导入人工稿、决定是否接受核验结果、最终保存。
- AI：检索/读取资料、形成简报与草稿、独立评审、提出缺口/停止。
- 自动化边界：不自动发布、不自动改用户输入、不自动合并外部文件；显式 CLI 操作。

## 已知风险与限制

- 真实模型在 12 轮内未完成“评审通过→保存”；真实返修未跑通。
- 评审有误报/未完成（11：1/6 误报、2/6 未完成）；不能把 AI 评审当绝对真值。
- 校准样本小，不是统计显著；真实单样本不代表生产质量。
- 资料/知识采用会使旧评审失效（本次修复）；没有自动重训知识。
