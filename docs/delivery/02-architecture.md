# 架构

当前实现事实以[架构入口](../architecture.md)为单一来源，本页给交付层关系：

```text
CLI任务interface
 ├─ 单主循环：模型选择动作，实际工具反馈继续
 ├─ 独立生成：获得自身所需简报、知识、素材及返修上下文
 ├─ 共享有界评估：生产核验 / 校准 / 有限回读对照
 └─ 保存与核实：完整文件及权威记录一致才完成
      └─ SQLite：输入、消息、版本、评审、尝试、账本、保存
```

Python、原生CLI、uv、openai SDK、DeepSeek deepseek-flash。真实/Mock在同一模型interface处变化，权限、数据库和输出隔离。后续适配只为已经存在的变化需求，不新增插件或跨模型协议平台。

当前默认24轮且任务内持久，schema8保留旧任务12轮并新增精确本地回执；有界评估3请求/2读取由版本化模式表提供。实际计量和状态规则集中，程序错误在外部交互之外不被普通业务失败吞掉。

独立审查与实测结果见[验收报告](10-repair-acceptance.md)；最终运行增量独立复查通过。
