# 架构

当前实现事实以[架构入口](../architecture.md)为单一来源，本页给交付层关系：

```text
CLI任务interface
 ├─ 单主循环：模型选择动作，实际工具反馈继续
 ├─ 独立生成：获得自身所需简报、知识、素材及返修上下文
 ├─ 共享有界评估：生产核验 / 校准 / 有限回读对照
 └─ 保存与核实：完整文件及权威记录一致才完成
      └─ SQLite：输入、消息、版本、评审、尝试、账本、保存
```

Python、原生CLI、uv、openai SDK、DeepSeek deepseek-flash。真实/Mock在同一模型interface处变化，权限、数据库和输出隔离。后续适配只为已经存在的变化需求，不新增插件或跨模型协议平台。

当前新任务默认24轮且任务内持久，已有任务沿用记录的上限，历史12轮任务保持12轮；schema8新增精确本地回执。有界评估3请求/2读取由版本化模式表提供。实际计量和状态规则集中，程序错误在外部交互之外不被普通业务失败吞掉。

新任务采用通用策略v2表，既有任务的查询、比较和执行按已记录策略版本加载。最新实测与207项回归见[新鲜eval报告](11-fresh-eval.md)；历史独立审查范围截至60249d6，见[审查记录](07-final-review.md)。后来的63ec7c8策略修复未新增独立子Agent审查。
