# 项目复盘

- 虽然开始时已经很注重Context了，很注重提供给模型的信息了，但是还是没有考虑全面，没有完整对齐，比如目前的工具设计我不太满意，有点太多了，并且虽然为了弥补，已经加入了前馈和反馈措施，但是工具调用出错的情况还是有点多，但是时间不充足，也就没时间进一步改进了。
- 包括Agent，由于Agent给出的结果是方案，本身的可验证性不强，确定性程序很难判断方案的质量，所以这里引入一个验收Agent去审阅，但是我这里开始并没有用程序将其设定为一个必须的措施，而是一个用主Agent去调用的工具，这里的设计是不好的，但是也由于时间有限，没能继续修正改进。
- 做好信息管理，文档管理是很重要的，因为LLM本质上只能接收Context，只有Context会影响它的输入（当然，我们不考虑调整温度等参数，也不考虑微调，这些不在实际应用场景中），关于这里，我有一些对Agent的自己的第一性理解，很希望有机会能够分享。
- 由于我本人还有课题以及一些其他事情要忙，所以本人的注意力反而是缺陷，如今，此时的瓶颈不在AI，反而在我自己，这里也是要思考的，关于Agent时代，究竟什么是重要的。
- 考虑垂直类Agent问题，要始终考虑几个方面：可验证性、可回退性、环境确定性、自主性、合规性，以及Agent的环境里，能获得的信息是否完备，还有获得信息的动作是与LLM的理解之间的摩擦，想好这些，肯定是没错的。
