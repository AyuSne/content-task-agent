## 小interface与深implementation

- CLI是公开任务seam，`run/resume`承担完整自主交付，`TaskService`提供创建、查询、显式更新及采用。测试由这些公开行为和导出进入；模型、文件和进程故障在外部交互处注入。
- `loop.py`组织单主循环，模型每轮一个动作；`model.py`在真实SDK与Mock脚本这个实际变化处提供adapter。无需新增通用模型/插件平台。
- `evaluation.evaluate`集中核验请求协议、权限、报告与上限；生产`review.py`负责本任务材料、尝试与持久状态，校准负责标签统计，对照负责实验条件。调用方通过实际读取和记录callback接入。
- `save.py`集中保存资格及核实。`save_preconditions`同时供资源重估使用；业务保存、新尝试收费、纯导出修复分别表达。导出由`export.py`从同一权威生成。
- `materials.py`/`knowledge.py`管理版本化正文；service显式采用时追加旧/新完整记录并更新当前投影。importer使用任务冻结资料。
- `strategy.py`集中创作方向及完整路径估算。默认通用v2表用于新任务，既有任务查询、比较和执行均读取其已记录版本；CLI回归见`test_strategy_task_scope.py`。原v1表保留供历史任务使用。
- `db.py`/`repository.py`保存输入、消息、产物、核验、处置、尝试、账本和保存事实。schema8增加精确本地回执；schema7引入旧任务12轮的持久上限，新任务默认24。

## 执行与事实

`create → run/resume → 查证/简报/策略 → 独立生成 → 完整方案 → 有界核验 → 必要处置/返修 → 核实保存`。图中不是固定模型动作序列；实际下一步依据工具返回，澄清/失败/无可行路径可停止。

核验完整且关键意见有据处理、资料缺口和关键阻塞已解决、版本适用、资源可行后，才可保存。optional不需要全部采纳；模型比较当前合格稿与有实质收益的改进。保存全文件核实后才提交完成；未知先核实，明确失败的新业务重试另计费。

业务尝试启动与模拟计量一起持久化；真实模型请求也先预登记、响应后更新同一记录。硬中断保留未知用量。恢复核实调用结果与进行中记录，补有依据回执，执行资源和轮数不重置。

系统/工具定义与顺序、实际加载知识和材料冻结；新要求、反馈、采用与恢复事实向后追加。存档本身不代表当前有效，通过输入/产物/评审/保存关联判断。JSONL Trace是可读投影，完整实际消息由SQLite和inspect保留。

模拟工具费单位CNY_cent，真实模型Token/金额、活动制作投放费用分开。纯估算不收费不推进模拟时钟；失败和中断保留已经启动的费用。真实与Mock身份、数据库、输出隔离。

## 修改入口

修改模型协议/回读规则时读`evaluation.py`及三个调用方的公开回归；修改保存/资源适用性时读`save_preconditions`与`test_version_adoption`；修改恢复时读`recovery.py`和真实子进程用例。先确认真实变化需求再引入新的seam。

五个本地动作的副作用与完整返回在同一事务，以确切请求身份关联；历史无精确回执只标中断，不靠时间窗口猜测，也不恢复时重算。导出按当前output关联review/save，程序拥有的元数据区分形成输入与当前有效输入；普通export保留外部活动稿编辑。
