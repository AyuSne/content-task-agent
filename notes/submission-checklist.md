# 提交清单

## 仓库材料

- [x] README：环境、安装、离线和真实运行、结果入口。
- [x] 源码、可执行测试、合成资料、费用与耗时表、业务 Skill。
- [x] 依赖文件、锁文件和 `.env.example`。
- [x] 需求、架构与设计、评估、AI 使用和复盘文档。
- [x] 三组真实输入与运行记录、六组离线实际输出、方案、执行报告和 Trace。
- [x] 当前代码的本地回归和样例哈希核对。

评审入口：[README](../README.md)、[样例索引](../examples/submission/README.md)、[构建思路](agent-design-rationale.md)。

## 提交前由候选人确认

- [ ] 将本次文档、样例和示例脚本纳入最终 Git 提交。
- [ ] 建立或配置 GitHub 仓库，推送准备提交的版本。
- [ ] 私有仓库按考试平台要求给予指定评审账号读取权限。
- [ ] 从最终提交取得 SHA，填写题号、仓库 URL 和 SHA。

在仓库根目录取得最终 SHA：

```powershell
git rev-parse HEAD
```

平台填写内容：

```text
题号：2
GitHub URL：填写最终仓库地址
commit SHA：填写最终提交的完整 SHA
```

`.env`、虚拟环境、缓存、原始运行数据库和临时目录留在本地。提交所需的脱敏输出已经单独归档，原始数据继续保留。
