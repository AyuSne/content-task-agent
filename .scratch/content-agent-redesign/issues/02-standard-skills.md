# 02: 从标准Skill取得方法并跨进程复用

**What to build:** 通过一次任务运行及inspect，看见Skill目录、明确预装、真实读取的正文/引用及其来源；后续进程沿用已采用内容。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

**Parent:** [内容任务规划Agent改造规格](../spec.md)

**User stories:** 40、41、42、43、44

## Acceptance criteria

- [ ] 使用标准名称/描述和SKILL.md载体，产品业务Skill与开发Agent技能分别管理，预装及工具读取使用同一来源。
- [ ] 创作与核验初始化时分别提供对应正文；目录标识已加载状态，预装不伪造assistant/tool调用。
- [ ] 单个受限读取入口支持正文和相对引用资源，正文条件指针可被实际读取；不开放任意仓库文件或自动执行附带脚本。
- [ ] 正文和引用内容按任务采用版本留存；显式采用更新保留来源、变化及适用性记录。
- [ ] 通过实际工具往返和CLI查询证明适用读取、条件引用、无效目标拒绝及跨进程复用。
- [ ] 保留有效业务方法并识别旧流程指引；涉及主Agent直接提交的最终正文与03同步切换，不让已装配请求承诺尚未接通的能力。

## Scope

本票交付可运行的知识获取与延续通路，不能只改文件名或产出未接入运行的加载器。无需等待01的费用规则改造；读取不另收生成费，但实际模型回合仍计数。

## Engineering and verification

以公开CLI、持久产物和状态/报告验收本票完整行为；本票实际使用的模型输入、工具反馈和适当测试随行为一起接通。复用现有真实/Mock seam，以小interface承载完整行为并集中规则；真实输入和外部交互处校验，内部依契约工作。保留必要的资源、版本、执行上限及核实保存要求，不引入假想adapter、静默兜底或双协议兼容层。旧测试按新行为调整，保留有效断言，真实与Mock证据分别说明。

前置票完成才进入实施前沿。具体提示词与字段按父规格契约细化；旧代码、历史资料、运行证据和未提交材料保留。
