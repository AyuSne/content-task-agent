# 13 与单次生成基线的对比评估

日期：2026-10-29。性质：**描述性对比，不是受控基准**。数据见 `comparison.json`。

## 对比口径

- **基线**：单次生成、无独立核验/返修，成本按一次生成 120 分、1 轮计；问题样本取自 11 的六对问题稿，人工标签全部为问题。
- **候选**：04 的完整确定性正常路径（4 轮/230 分/1 次评审通过/5 个交付文件）；06 的返修样例（7 轮/430 分/2 次评审/1 次返修/2 个方案版本）。
- **真实候选**：12 的 `t_b928246de900`（12 轮/240 分模拟费用/14 次真实请求/评审 fail 4 must_fix + 2 optional/未保存）。
- **评审校准**：11 的六对真实校准（问题稿 6/6 命中；合格稿误报 1/6 P6；未完成 2/6）。

## 结果摘要

| 维度 | 单次基线 | 完整候选（确定性） | 真实候选 |
| --- | --- | --- | --- |
| 评审通过 | 0/6（问题稿） | 正常 1/1；返修 1/1 | fail（4 must_fix） |
| 证据/硬约束 | 无核验，问题稿含无依据能力、遗漏、矛盾等 | 有证据关联、缺口检查、disposition | 评审指出录屏/音乐误用、预算不自洽、引文不支撑 |
| 返修 | 无 | 1 次返修后通过 | 3 轮内未形成 v2，12 轮触顶 |
| 轮数 | 1 | 4 / 7 | 12 |
| 模拟费用 | 120 分/次 | 230 / 430 分 | 240 分（真实金额未知） |
| 真实用量 | 未跑真实单次基线 | Mock | 14 请求；201,549 输入 / 15,067 输出；140,010 ms |
| 安全边界 | 无核验/保存边界 | 核验+保存+证据缺口+输入版本 | 未保存，保持 incomplete |

## 结论

1. 完整管线在确定性任务上能形成“核验→保存”的可核实交付，并在返修样例中保留 v1、生成 v2、再次核验；单次基线不具备这些机制。
2. 机制存在不等于内容质量：真实候选仍被评审指出 4 个 must_fix，且 11 的评审自身有 1 个误报和 2 个未完成。不能声称完整管线显著优于基线。
3. 成本/时间：完整路径比单次生成多 110–310 分模拟费用和 3–6 轮；真实模式下 12 轮上限是实际瓶颈。是否值得取决于质量收益，本次数据不足以做统计显著结论。
4. 返修并不必然改善：06 的确定性样例通过，但真实候选未完成返修；12/13 都不伪造改善比例。

## 限制

- 基线不是真实单次 API 调用，而是校准问题稿；没有跑同一任务的单次真实基线。
- 样本小、任务不同、评审本身有误报/未完成；不能外推生产质量或显著优劣。
- 完整候选的确定性数据来自 Mock；真实候选只有一次且未保存。
