# 学习打卡30秒剪辑介绍：卡点这块，自己说了算

> 本版本已完成内容核验与保存核实；后续制作素材仍按下文状态处理。

## 活动概述

- 目标：让18-24岁大学生了解帧剪的自动卡点可把选中片段对齐到节拍点，并支持逐段微调与一键重新卡点，引导下载/试用；不承诺涨粉、收益或爆款。
- 受众：18-24岁大学生（用户确认）；依据为 M-003 合成样本中学习打卡为高频创作类型、倾向30分钟内成片、对“一键出片”信任度一般且更愿保留手动调整。样本仅代表该合成样本，不外推至全体大学生。
- 形式：单条30秒竖屏短视频（9:16），抖音为主发布渠道、视频号/B站为次；一条主视频构成完整活动方案。
- 主题：学习打卡30秒剪辑介绍：卡点这块，自己说了算

## 创作策略

- 选定：user_scenario
- 理由：受众为18-24岁大学生，M-003 合成样本（样本120名，不可外推）显示学习打卡是其常制作类型且受访者更愿保留手动调整。以校园学习打卡情境开场建立共鸣，中段用帧剪 4.2+ 操作录屏承载「自动卡点」与「逐段微调」两项正式能力演示。情境画面只表达场景，产品能力由 M-001 支持的操作录屏证明，符合 M-005 与 M-004 品牌规则。
- 未选 functional_demo：纯录屏功能演示缺少与目标受众的情境连接，开场留存与吸引力弱于情境切入；能力证明部分与情境路线相同，未带来额外收益。
- 未选 tutorial：30秒内分步教程会挤压两项核心能力的展示与结果呈现，容易堆步骤而弱化「逐段微调」的表现；本任务只需介绍性演示而非完整教学。

## 内容安排

1. 30秒主视频《学习打卡卡点，自己说了算》｜情境开场引出学习打卡卡点需求，录屏演示自动对齐节拍与逐段微调两项正式能力｜30 秒｜抖音（主）；视频号/B站为次
2. 配套发布文案与话题（文字，可直接使用）｜文字文案（非视频）：说明可逐段微调、可一键重新卡点，附建议话题标签；不含效果承诺。可直接使用：“学习打卡素材。选一段节奏清晰的音乐，点自动卡点，片段会按节拍对齐；某一段偏了，就逐段拖动微调，也能一键重新卡点。复杂变速或弱节拍的音乐需要手动调一下。”｜15 秒｜抖音/视频号/B站
3. 评论区答疑要点（文字，可直接使用）｜文字文案（非视频）：回应“卡不准怎么办”。可直接使用答疑文本（依据 M-001）：“自动卡点会分析音乐节拍、把片段对齐到节拍点，但不承诺对所有曲风都准确；复杂变速或弱节拍的音乐需要人工调整，可以逐段微调，也能一键重新卡点。”｜10 秒｜抖音/视频号/B站

## 主视频脚本（30 秒）

### 1. 0-3s

- 画面：竖屏快切：宿舍书桌前的手机屏幕播放学习打卡片段（笔记+计时器），随后切到教室、操场的简短镜头，制造“这些片段怎么卡点”的钩子。情境画面取自素材包 M-005 中教室、宿舍剪辑两条场景片段。
- 音频：轻快背景音乐（待获取授权，暂用试听版占位；未获授权则改用已授权曲目）
- 字幕：学习打卡素材，怎么卡点更顺？
- 素材：M-005, M-006
- 证据：无

### 2. 4-15s

- 画面：帧剪 iOS/Android 4.2+ 操作录屏（待制作，运营录制）：导入学习打卡素材→选择音乐→点击“自动卡点”→时间线片段自动对齐节拍点；字幕标出“自动分析音乐节拍，对齐到节拍点”。录制时界面不得出现实验性功能入口。
- 音频：背景音乐持续，卡点对齐瞬间加轻微“嗒”音效（音效待制作/获取授权）
- 字幕：自动卡点：分析音乐节拍，把选中片段对齐到节拍点
- 素材：无
- 证据：E1

### 3. 16-24s

- 画面：同一录屏继续（待制作）：手势拖动某一段片段逐段微调到更准的节拍位置；再点击“一键重新卡点”演示恢复自动对齐。字幕提示“逐段微调 / 一键重新卡点”。
- 音频：背景音乐持续，微调操作配轻微点击音效（待制作/获取授权）
- 字幕：可逐段微调，也可一键重新卡点
- 素材：无
- 证据：E1

### 4. 25-30s

- 画面：25-28s：成片预览，学习打卡片段随节拍切换，画面回到校园情境（M-005 教室/宿舍场景），叠加文字“自动卡点 + 逐段微调，卡点自己说了算”； 28-30s：切结尾品牌标版（待制作），不占用成片预览时段。
- 音频：背景音乐渐弱收尾（授权状态同上）
- 字幕：自动卡点 + 逐段微调，卡点自己说了算
- 素材：M-005, M-006
- 证据：E1
