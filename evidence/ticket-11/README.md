命令：`cta --mode real calibrate --output evidence/ticket-11/real-calibration.json`（DeepSeek `deepseek-flash`，非思考、非流式、重试 0）。

- 问题稿命中：**6/6**；漏检 0。
- 合格稿误报：**1/6**（P6：评估器把 4.2 版本前提、30 秒依据等列为必须项；部分属可争议的严格判断）。
- 合格稿未完成：**2/6**（P3、P5 在 3 次请求内未返回报告，按 incomplete 计，不算通过）。
- 合格稿可选建议：9 条；问题稿可选建议：6 条。
- 请求 19 次；输入 51,487 / 输出 15,518 tokens；缓存命中 46,331、未命中 5,156；采得 API 耗时 112,159 ms；真实墙钟 112.3 s；未知用量 0。
- 模拟费用：`not_applicable`（校准不创建内容任务，不进入任务模拟预算）。
- 结果：`real-calibration.json`；首轮 21 请求的旧结果已被本轮覆盖，失败/限制记录在本 README。

解释：校准说明评估器能识别全部已知问题稿，但对合格稿存在过严/未完成；因此不能据此宣称“评审可靠”或生产质量。P6 的误报与 P3/P5 的 incomplete 均保留，不作为通过。
